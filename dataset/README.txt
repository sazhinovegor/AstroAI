AstroVision AI v1.0 — структура датасета

Обязательны ТРИ папки класса в каждом разделе:

dataset/train/galaxies/
dataset/train/nebulae/
dataset/train/other/
dataset/val/galaxies/
dataset/val/nebulae/
dataset/val/other/
dataset/test/galaxies/
dataset/test/nebulae/
dataset/test/other/

galaxies — только реальные фотографии галактик.
nebulae — только реальные фотографии туманностей.
other — все изображения, которые система должна отклонять: звёзды без туманностей,
планеты, Луна, Солнце, скопления звёзд, кометы, астероиды, земные пейзажи,
люди, животные, схемы, графики, скриншоты, текст и случайные фотографии.

Класс other критически важен: без примеров посторонних изображений нейросеть
не может надёжно научиться отказывать. Нужны разнообразные и репрезентативные
примеры; не ограничивайтесь одним типом «неподходящих» снимков.

Для конференционного исследования разделяйте данные по астрономическим объектам:
все кадрирования и варианты обработки одного объекта должны быть только в одном
разделе. Заполните metadata.csv (path, object_id, source, license).
Перед обучением выполните:
python audit_dataset.py --data_dir dataset
