# AstroVision AI — v1.0 (Open-set Research Edition)

Исследовательское приложение Streamlit для распознавания **только двух целевых типов астрофотографий**:
- `galaxies` — галактики;
- `nebulae` — туманности.

Добавлен третий внутренний класс `other`. Он не является результатом для пользователя: его назначение — научить модель отклонять неподходящие изображения. Если модель выбирает `other` либо не достигает порога уверенности, приложение выводит ошибку: «Изображение не относится к галактикам или туманностям».

> Важно: это не гарантия распознавания любых неизвестных изображений. Надёжность отказа зависит от разнообразия класса `other`, качества разметки и независимой проверки. Модель нельзя считать обученной, пока не подготовлен датасет и не запущено обучение.

## Крупные изменения v1.0

1. **Open-set поведение через класс отказа.** Обучение теперь требует три класса: galaxies, nebulae и other.
2. **Единый инференс-путь.** Одиночная и пакетная классификация используют одну функцию `predict_image`, одинаковую предобработку, EXIF-коррекцию и TTA.
3. **Строгий пользовательский вывод.** На экране успешным результатом может быть только «Галактика» или «Туманность». Класс `other` скрывается за сообщением об ошибке.
4. **Отказ при низкой уверенности.** Снимок не получает положительную классификацию, если максимальная оценка ниже порога.
5. **Пакетная обработка.** Неподходящие и повреждённые файлы получают отдельные статусы; ошибка одного файла не прерывает очередь.
6. **Научный контроль.** В отчётах сохраняются три класса, поэтому можно измерять precision/recall/F1 для `other` и долю ложных допусков.

## 1. Установка

Рекомендуется Python 3.11/3.12 и NVIDIA GPU с совместимой сборкой PyTorch CUDA.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Проверка CUDA:

```powershell
python -c "import torch; print('CUDA:', torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

## 2. Подготовка данных

Структура обязательна:

```text
dataset/
  train/
    galaxies/
    nebulae/
    other/
  val/
    galaxies/
    nebulae/
    other/
  test/
    galaxies/
    nebulae/
    other/
```

- `galaxies`: только галактики.
- `nebulae`: только туманности.
- `other`: всё остальное, что система должна отклонять (звёзды, планеты, Луна, Солнце, скопления, кометы, земные фото, люди, схемы, скриншоты, графики и т. д.).

**Не пропускайте класс `other`.** Если в нём нет разнообразных примеров, модель будет склонна ошибочно относить посторонние изображения к одному из двух целевых классов. Используйте независимые объекты в train/val/test; не переносите кадрирования одного объекта между разделами. Заполните `dataset/metadata.csv` с `path`, `object_id`, `source`, `license`.

Проверка:

```powershell
python audit_dataset.py --data_dir dataset --require_metadata --require_provenance
```

Подготовка сбалансированных разделов из `dataset/raw/`:

```powershell
python prepare_dataset.py --help
```

## 3. Обучение

```powershell
python train.py --data_dir dataset --epochs 20 --batch_size 16 --seed 42 --require_metadata --require_provenance
```

При нехватке VRAM используйте `--batch_size 8` или `4`. Обучение автоматически выберет CUDA, если она доступна.

## 4. Запуск приложения

```powershell
streamlit run app.py
```

Разделы:
- **Анализ снимка** — загрузка одного изображения, классификация или отказ;
- **Пакетный анализ** — обработка нескольких изображений и CSV;
- **Обучение модели** — запуск и мониторинг обучения;
- **Научная статистика** — метрики и матрица ошибок;
- **О проекте** — описание архитектуры.

## 6. Ограничения и корректная научная формулировка

Ни одна обычная softmax-модель не может гарантировать отказ для абсолютно любого неизвестного изображения. В этой версии `other` — обучаемый класс отказа, а порог уверенности — дополнительная эвристика. Чтобы проверить требование «принимать только галактики и туманности», сформируйте отдельный OOD-набор из типов изображений, отсутствующих в обучении, и измерьте:
- долю ложных допусков посторонних изображений (false acceptance rate);
- долю отклонённых целевых снимков (false rejection rate);
- precision, recall и F1 для каждого класса;
- результаты отдельно для разных групп `other`.

Не заявляйте абсолютную точность или гарантированное распознавание неизвестных объектов без такого тестирования.
